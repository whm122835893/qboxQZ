# QBOX 数据库实体模型设计 v3（对齐司南数据库规范 · 补齐版）

> 版本：v3.0　日期：2026-10-26
> 基线：**《司南数据库文档 v2.2》33 张规范表**（用户提供 PDF：设计决策 13 条 + 查缺补漏 8 条 + 业务约束 24 条 + 索引清单）。
> 本文档 = 司南基线 ∪ QBOX 项目特有业务表，共 **39 张表**。
> 读法：凡标注「基线表」的，字段定义以司南 v2.2 对应章节为准，本文只列 **QBOX 补充/差异字段**；凡标注「QBOX 特有」的，给全字段定义。所有 QBOX 特有字段均有源站抓包或页面实证，来源列已标注。

## 一、对齐决策汇总（在司南 13 条规范决策 + 8 条查缺补漏之上新增）

| # | 决策 | 说明 |
|---|------|------|
| D1 | categories 并入 **series** | QBOX 市场板块（getSeries 实测：推荐/破茧/生肖系列/我的关注/全部）同时承担司南 categories 的「分类 tab」职责，且额外携带寄售/购买时段配置（resale_put/buy_start_time 实测），故保留单表 series，补 code/icon/sort_order 字段对齐司南 |
| D2 | 实名信息内联 **users** | 司南规范将 is_realname/real_name/id_card 内联用户表（AES-256/SM4 加密）；QBOX 原 user_realname 独立表取消 |
| D3 | QBOX 支付渠道补 **'huifu'** | 源站挂单 income_type=['huifu']、订单 pay_way='huifu'（汇付收银台 hfpay.cloudpnr.com 实测），payments.payment_method 枚举扩展 |
| D4 | resale_listings.status 扩展 **'locked'** | 源站实测：买家打开购买弹窗挂单即被锁定（状态 4「锁单中」，灰底不可买）；对应 user_collectibles.status='frozen' |
| D5 | **chain_task 保留独立表** | QBOX 源站实测上链任务为独立对象（task_id/tx_hash/status/class_id/nft_id/api_data），司南以 user_collectibles.mint_status 内联；两者并存：user_collectibles.mint_status 为展示态，chain_task 为任务明细 |
| D6 | goods 聚合冗余字段保留 | min_price/max_price/market_fluctuate_new/market_value/deal_num/sell/buy 为源站实测响应字段（列表页直读），由市场定时汇总维护 |
| D7 | QBOX 特有交易表保留 | 求购 beg_buy_orders / 委托 entrust_orders / 交易流水 trade_records 在司南基线中不存在，但为 QBOX 已实现页面（求购/委托/交易信息）所必需 |
| D8 | 龙晶商城保留独立 | crystal_goods + exchange_records（QBOX 龙晶体系：三色龙晶 + 兑换藏品，order.crystal_type 实测）；wallets.points 不承担龙晶记账，龙晶余额按 crystal_yellow/purple/blue 于 wallets 扩展 |
| D9 | 抽奖活动补 **lottery_activities** | 司南 lucky_draw_prizes.activity_id 引用「抽奖活动/期数」但基线未建活动表，QBOX 补齐 |
| D10 | 订单补充 QBOX 实测字段 | 空投溯源 uc_ids/airdrop_record_id、服务费三件套、collection_code JSON、c_goods_id、surplus_time_text、artel_order 保留（均有实测） |

## 五、实体关系（ER）

```
users 1──1 wallets                     (wallets.user_id UNIQUE)
users 1──N wallet_transactions         (wallet_transactions.user_id，纯日志)
users 1──N verification_codes          (phone 关联，日志)
users 1──N invite_records              (inviter_id；invitee_id UNIQUE 一人被邀一次)
invite_records ─N:1─ airdrop_records   (inviter/invitee_airdrop_record_id 奖励落账)

series 1──N collectibles               (collectibles.series_id；板块承担分类 tab + 寄售时段)
collectibles 1──1 blind_boxes          (blind_boxes.collectible_id UNIQUE)
blind_boxes 1──N blind_box_items N──1 collectibles (prize_collectible_id)

users 1──N user_collectibles N──1 collectibles
user_collectibles 1──1 resale_listings (user_collectible_id 在售唯一)
user_collectibles 1──N chain_tasks     (task_id UNIQUE 关联，D5)
users 1──N user_favorites N──1 collectibles (UNIQUE(user_id,collectible_id))

users 1──N orders ─1:1─ payments       (payments.order_id UNIQUE；payment_method=balance 扣 wallets)
orders N──1 resale_listings            (orders.resale_listing_id，市场单)
orders 1──N user_collectibles          (order_id，purchase 来源回填)

resale_listings 1──1 orders(成交) → 回写 status='sold' + user_collectibles.status='transferred' + 归属迁移
users 1──N transfers（from/to 双向索引；确认后迁移 user_collectibles.user_id）
collectibles 1──N beg_buy_orders / entrust_orders / trade_records
collectibles 1──N market 流动性聚合（min_price 等冗余字段由 resale_listings/trade_records 汇总）

synthesis_activities 1──N synthesis_materials N──1 collectibles(材料)
synthesis_activities.result_collectible_id → collectibles(产物，防死循环：产物不得出现在材料中)
users 1──N synthesis_records 1──N synthesis_record_items N──1 user_collectibles(消耗)

lottery_activities 1──N lucky_draw_prizes 1──N lucky_draw_records N──1 users
                                       (lucky_draw_records.user_collectible_id 可空=谢谢参与)
users 1──N check_in_records            (UNIQUE(user_id,check_in_date) 每日一次)

airdrop_activities 1──N airdrop_snapshots / airdrop_records / airdrop_eligibilities
airdrop_records 1──1 user_collectibles (source='airdrop' + airdrop_record_id 溯源，D13)
invite_activities 1──N invite_records  (奖励经 airdrop_records)

collectibles 1──N artifacts?           (无外键：artifacts 独立内容表)
crystal_goods 1──N exchange_records → user_collectibles(兑换入账) / orders(orderType=4 详情)
announcements / banners / community_groups / site_settings —— 独立内容与配置域
```
