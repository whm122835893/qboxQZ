### 认证机制（实测）

```
POST https://api.xiyanwl.asia/api/user/login
Body: {"account":"17587881293","password":"whm981004"}
响应: {"code":1,"msg":"登录成功","time":"<unix秒>","data":{"userinfo":{...},"token":"<36位>"}}
后续请求头: token: <登录返回的token>  +  version: 1.0.0
```

- token 长度 36 位（FastAdmin User token 插件风格）
- 未登录可浏览首页/市场/公告；「我的」等页面登录后展示数据
- 错误密码实测返回：`{"code":0,"msg":"密码不正确"}`，前端以黑色顶部 toast 展示

### 响应包统一结构

```json
{ "code": 1, "msg": "xxx", "time": "unix秒", "data": { ... } }
// 分页列表 data: { "total":0, "per_page":15, "current_page":1, "last_page":0, "data":[] }
```

## 5. 复刻方案（已锁定）

| 层 | 选型 | 理由 |
|-----|------|------|
| 前端 | Vue 3.5 + Vite 5 + vue-router 4(hash) + Pinia + Vant 4（按需） | 对应 uni-app H5；hash 路由 1:1 复刻原站 111 条路径 |
| 适配 | 自研 vite px→vw 插件（1px=100/750 vw） | CSS 直接书写原站 rpx 数值，像素级自适应 |
| 后端 | ThinkPHP 8 + FastAdmin 风格响应结构 | 与原站接口结构一致（code/msg/time/data），联调零改造成本 |
| 数据库 | MySQL 8（utf8mb4） | 见《02-数据库设计文档》 |
| Mock | 抓包实录回放（src/api/mock-data.js，19 接口） | 后端未就绪时前端独立运行，规则9合规 |
| 图片/字体 | 全部下载自原站（public/static/**, 60+ 文件） | 规则4：不用 SVG 占位 |

## 6. 已知边界与依赖说明（规则9记录）

1. 顶象验证码（dingxiang-inc）为第三方风控服务，独立项目不依赖；登录验证改为本地图形验证码/后端验证码，已在 API 文档标注差异。
2. 短信发送为运营商能力，独立项目由自建后端对接或 mock（验证码 123456），已标注。
3. 原站 `api.xiyanwl.asia/uploads/` 部分历史图片（appBigLogo 等）已 404/无权限，能用则用，缺失的以静态资源库中等价图替代并记录。
4. 支付（钱包A 三方持牌支付）属资金通道，独立项目按 mock 处理，不做真实支付对接。
