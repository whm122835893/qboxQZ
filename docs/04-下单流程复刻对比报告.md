```
/pages/market/market                       市场页（板块卡：推荐 9,999.00 / 破茧 -- / 生肖系列 --）

       │     └─ 「立即购买」→ 底部半屏弹窗「数字藏品订单信息」→「立即支付」
       │           → POST /api/market/market/createOrder（本地 mock 闭环）
       │           → /pages/order/list（新单「待支付」+ 去支付按钮）
       │                 └─ 点订单卡 → /pages/order/defaultDetail?id={id}&orderType=2
```

## 三、本次修复的 UI 差异（逐项对照原站计算样式）

1. **订单详情页（defaultDetail）整页重写**：原实现是通用「商品信息/订单信息」模板，与原站不符。
   原站实测布局：导航标题=状态文案（订单已取消 / 订单空投转入成功）→ 藏品卡（封面 160×160r + 名称 28r Bold + 当前藏品最高价/求购价 22r 灰）→ 金额卡（藏品金额/应付金额/支付钱包 三行）→ 购买订单卡（订单编号+复制图标 / 支付方式 / 支付时间）→ 底部「取消订单 260×92r 白底蓝框 + 继续购买 400×92r 蓝底」r18。
   状态文案映射（实测样本）：status=3 → 订单已取消；status=2+uc_ids → 订单空投转入成功；其余按语义推导（已在代码注释与 API 文档标注推断）。支付时间 pay_time 为 null 时取 createtime（两样本一致）。
2. **订单列表卡重排**：订单号 22r 灰（旧为 26r 深色）、封面 120×120r、名称下独立「购买数量 N」、右列「购买金额/¥金额（28r #8c8c8c 数字体）」、右箭头 16×24r、时间 20r、卡白底 r20 页底 #f7f7f7。
3. **挂单列表页 4 处**：页底 #f7f7f7；「市场价格」选中下划线 48×6r 蓝；寄售/求购/委托 改为胶囊（88×52r r12，选中蓝底白字）；价格列箭头=升序图 / 编号列=普通图（本地原先装反）。
4. **市场页涨跌幅换行**：百分比文字 22rpx、容器 110rpx 内按 pre-line 换行（3233.00% → 3233.0 / 0%），与原站一致；板块卡价格千分位（9,999.00）。
5. **快捷下单弹窗**：封面右侧补「名称 28r + 流通量/发行量 22r」两行（旧版只有规格一行）。
6. **寄售详情创作者卡**：头像加载失败兜底（原站该处 src 为空渲染灰底空块）。
